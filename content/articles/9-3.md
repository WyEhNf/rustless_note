## 尾值与返回

函数声明已经给出返回类型。函数体可以通过尾表达式提供这个类型的值，也可以用 `return` 提前返回；这两条路径需要分别理解。

```rust
fn a() -> i32 { 1 }
fn b() -> i32 { return 1; }
fn c() -> i32 { return true; } // 错误
```

`a` 的块把 `i32` 期望交给尾部整数。`b` 的 `return` 按当前函数结果检查 1，然后自身得到 `Never`，说明这里不会正常落到下一步。`c` 虽然同样跳走，携带值 `true` 仍是 `bool`，无法作为 `i32` 返回。持续发散的函数体可以满足结果要求，因为它没有正常返回的路径。这个规则不会免除 `return` **携带值的检查**。
