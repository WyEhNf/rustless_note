## 基础值的类型

表达式检查最终会走到字面量或名字，再从这些结果组成数组、结构体等值。这一章把基础值、路径查找和聚合构造连起来，说明类型要求怎样逐步落到每个具体内容上。

整数依据后缀、整数 `expected` 和默认 `i32` 依次取型；`true` 固定为 `bool`，`()` 固定为 `Unit`。它们即使没有名字，也仍是独立的语法节点，需要留下检查结果。数组下标希望得到 `usize`，函数参数可能希望得到 `i32` 或 `u32`，同样的无后缀数字就可能在不同位置获得不同类型。

## 名字的来源

```rust
const X: i32 = 1;
fn main() {
    let X = true;
    let y = X;
}
```

`y` 的初值先找到局部 `X`，所以得到 `bool`。全局常量仍然存在，只是这次使用被更近的绑定遮住。查找结果需要留下声明身份，不能仅凭拼写把两个 `X` 混成同一对象。

多段路径如 `Point::read` 根据关联名查找，`Self::N` 先根据当前所属类型展开。找到函数后继续读签名，找到常量后取得声明类型和求值结果，找到局部值则还要考虑绑定权限。内建容器路径也有专门的候选和类型实参要求。

## 数组的元素与长度

```rust
const N: usize = 2;
let a: [u32; N] = [1, 2];
let b: [i32; 0] = [];
let c = [Box::<i32>::new(1); 2]; // 多次重复要求 Copy，Box 不符合
```

`a` 的标注把 `u32` 要求传给两个元素，求得 `N` 为 2 后再比较长度。`b` 没有元素可供推导，但标注提供了 `i32`，实际长度也符合零。没有标注的空数组则缺少确定元素类型的依据。

重复数组还要确定编译期次数。次数大于一时，当前规则要求元素支持 `Copy`，因此 `c` 不能靠重复同一个 `Box` 值通过。次数为零或一时不触发这项多次复制要求，次数本身仍要属于受支持的常量范围。

## 结构体的字段

```rust
struct Point { x: i32, y: u32 }
let p = Point { x: 1, y: 2 };
let bad = Point { x: true }; // x 的类型不符合，同时缺少 y
```

`Point` 的声明分别给 `x` 与 `y` 的初值提出 `i32` 和 `u32` 要求。构造整体得到 `Point` 类型，但字段名与字段值还需要逐个检查：未知字段、重复字段、缺失字段和初值类型不符分别说明不同问题。

**聚合值的整体类型，要由每个组成部分和整体结构一起确认。**

本章先把字面量与路径放在一起，说明基础结果从哪里来，再把数组与结构体构造放在一起，观察要求怎样传给元素和字段。名字出错或字段名未知时，也尽量继续检查内部表达式中的独立问题。
