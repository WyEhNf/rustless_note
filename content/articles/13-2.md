## 二元运算

二元运算都有左右两个孩子，但左右需要什么类型、整体得到什么结果，要**由操作符决定**。这里先把几种常见情况放在一起比较。

```rust
1i32 << 2u32; // 两侧为整数即可
1i32 + 2u32;  // 整数种类不匹配
true & false; // 布尔按位运算
true && false; // 逻辑运算
```

移位允许左右整数种类不同，结果按左侧类型。普通整数算术要求种类匹配。位运算可以处理两个 `bool`，逻辑运算要求原始类型为 `bool`。相等比较还需要 `PartialEq`；大小比较有自己的引用及内部标量要求。部分算术可以剥去一层共享引用，逻辑运算不能直接照搬。这些规则分别决定允许什么以及结果是什么，不能用一条笼统的“两侧类型相同”覆盖全部情况。

相等比较还需要类型提供 `PartialEq`。即使两边类型一致，也仍要说明这个类型允许怎样比较。

```rust
#[derive(PartialEq)]
struct Point { x: i32 }
let same = Point { x: 1 } == Point { x: 2 };
```

两侧都是 `Point`，还需要 `Point` 支持 `PartialEq`，才能按字段比较 `x`。去掉相应能力声明后，仅凭两侧类型相同不足以通过这项检查。`PartialEq` 允许某些值不满足自反性。完整 Rust 中的 NaN 可以说明这个差别：NaN 与自身比较也为 `false`。`Eq` 进一步要求自反性。

当前没有浮点类型，这个概念差别仍有助于理解为什么 `Eq` 依赖 `PartialEq`，而相等运算检查的是 `PartialEq`。

大小比较也有自己的规则，尤其在操作数带引用时，不能直接套用函数参数的适配方式。

```rust
let mut a = 1;
let b = 2;
let left = &mut a;
let right = &b;
left < right; // 当前规则拒绝这一方向
```

左边可变引用、右边共享引用的这一组合，在当前比较规则中受到限制。不能因为两边最后都指向 `i32` 就直接放行。检查还会逐层确认两侧是否同时为引用，剥开后要求内部类型一致，并且属于整数或 `bool`。这是一组具体比较规则，与把参数中的可变引用适配成共享引用不同，不能把调用适配结论原样搬过来。

## 赋值与写回

赋值先要知道左边是哪一处位置、具有什么类型，再以这个类型检查右边。右边符合要求以后，**左边仍需要允许写入**。

```rust
let mut x: u32 = 0;
x = 1;
x = true; // 类型不匹配
```

第一处赋值从 `x` 得到 `u32` 要求，无后缀的 1 可以按 `u32` 检查。第二处 `true` 固定是 `bool`，无法满足要求。如果 `x` 没有 `mut`，即使右侧类型正确，也会因目标不可写失败。整个赋值表达式正常结束时得到 `()`，类型是 `Unit`。这里说明的是检查顺序。运行时遇到带副作用的左右表达式时，具体求值顺序仍需按语言执行规则理解。

复合赋值还包含一次运算。除了能够写回目标，也要确认这组操作数符合对应运算的要求。

```rust
let mut x: i32 = 1;
x += 2;
x <<= 1u32;
```

`x` 是可写整数位置。加法赋值检查整数要求，移位赋值允许右侧使用另一种整数类型，最终写回左侧类型。当前复合赋值检查没有把每个操作符的限制都完整写成与普通二元运算相同的规则。特别是 `bool` 进入标量分支后，不能推断任意复合算术都已经正确支持。因此这些例子选用明确的整数组合。若讨论更广范围，需要逐个操作符确认。

方法或容器操作也可能修改值，不过它们检查的是接收者的访问方式。可变引用绑定本身是否带 `mut`，仍要与所指目标的权限分开看。

```rust
let mut v = Vec::<i32>::new();
let r = &mut v;
r.push(1);
```

`r` 的绑定本身没有 `mut`，但它提供对 `Vec` 的可变访问，因此可用于需要可写接收者的 `push`。若先经过共享引用，已有的限制会阻止后面恢复写权限。`Box` 也可能需要继续向内部看，普通值则结合是否为位置及绑定 `mut` 判断。这种接收者检查与直接赋值检查用途不同。直接赋值看目标表达式已经得到的 `place` 与可写结论。

## 显式转换

写出 `as` 就明确提出了一次转换请求。当前支持整数之间转换，以及 `bool` 到整数的转换；每一层转换都需要分别确认。

```rust
let a = 1i32 as u32;
let b = true as i32;
let c = 1i32 as bool; // 当前不支持
let d = 1i32 as u32 as usize;
```

`a` 改为无符号整数，`b` 把布尔值转换为整数。`c` 反向转换没有被当前规则允许。`d` 依次转换，最后结果是 `usize`。检查时先得到原表达式类型，再解析目标，确认二者属于**允许的组合**。完整语言还可以规定浮点、原生指针和枚举到整数等转换。那些写法需要额外规则，也可能涉及截断、范围或访问安全问题，不能由整数转换直接推广。
