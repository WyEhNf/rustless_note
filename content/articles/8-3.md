## main 的要求

全局声明准备完成后，Pass1 还要确认程序能够按约定开始。这里要求存在一个**顶层 `main`**，它的参数与返回类型需要符合固定形式。

```rust
fn main() {} // 符合要求
// 以下分别违反入口要求：
// fn main(x: i32) {}
// fn main() -> i32 { 0 }
// fn main<'a>() {}
```

空参数且省略结果类型的 `main` 返回 `Unit`，满足这里的入口形状。带值参数需要调用者传入数据，带非 `Unit` 结果改变了入口要求，生命周期参数也在当前检查范围中被拒绝。用户类型泛型本身尚未完整支持。即使某个结构体有 `Type::main`，它也是关联函数，不能满足顶层 `main` 必须存在的要求。
