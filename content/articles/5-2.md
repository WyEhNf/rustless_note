## 全局登记表

**全局登记表按名字找到全局声明，供各个函数共同使用。**

```rust
struct Point { x: i32 }
const LIMIT: i32 = 10;
fn larger(x: i32) -> bool { x > LIMIT }
```

查 `Point` 可以找到结构体声明，继续取得字段 `x` 的类型；查 `LIMIT` 可以取得常量的声明类型、求值进度与结果；查 `larger` 可以取得参数和返回类型。关联成员还带着所属类型，例如 `Point::read`。

表里的信息随着 Pass1 逐步补齐，并在整次分析中保留。某个函数体检查结束后，其他函数仍然可以使用这些声明。名字查找负责找到记录，记录中的类型、字段或签名再供具体检查使用。

## scope 符号表

局部名字随块变化，需要另有一组表。**`scope` 符号表保存当前作用域里的名字与绑定。** 绑定记录通常包括类型、可变性和声明编号。

```rust
let x = 1;
{
    let x = true;
    let only_here = 3;
}
let y = x;
let z = only_here; // 错误：已经离开它所在的块
```

内层块增加一层局部表，查找从内向外，找到第一条匹配就停止。退出内层后，`y` 找到外层整数 `x`；`only_here` 已经不在查找范围里，所以 `z` 的初值出错。

这里先说明表的作用范围。[局部绑定与循环上下文](/posts/9.2)再讨论同名新绑定何时生效，以及块与循环怎样分别维护。局部查找范围退出后，已经确认的名字关系仍然可以保存。

## 节点与声明编号

保存名字关系时，需要同时指出使用处和声明。`NodeID` 区分源码中的节点，`SymbolID` 区分声明身份；这里可以直接用声明节点的编号作为它的 `SymbolID`。

```rust
let x = 1;
let z = x + x;
```

假定声明 `x` 的编号为 10，两个使用点的节点编号为 12 和 13。两处使用各有 `NodeID`，但都关联声明 10。加法整体另有节点编号 14，它产生计算结果，无须额外关联某个声明；参与计算的声明可以从孩子继续找到。

**一个声明可以被多处引用，每个使用节点则保留自己直接关联的声明。**

声明还可以有所属关系，记作 `owner`。字段属于结构体，参数属于函数，关联方法也有所属类型。

```rust
struct Point { x: i32 }
impl Point {
    fn add(&self, value: i32) -> i32 { self.x + value }
}
```

字段 `x` 与方法 `add` 属于 `Point`，参数 `value` 属于 `add`。解析大写 `Self` 时，当前所属类型提供了依据。小写 `self` 则是接收者绑定：检查时可以建立它的记录，不要求原树额外具有普通参数节点；这里可以复用所属方法的身份。

编号与对象连接都用于在分析期间找到对应记录。它们不会规定 `value` 在运行时究竟放在寄存器、栈上还是被优化掉。

## 表达式事实表

**表达式事实表按节点保存检查结论。** 它说明这一次表达式得到什么类型、关联哪个声明，以及是否指向可修改的位置。调用还会留下具体目标与必要的隐式调整。

```rust
let mut x = 1;
let y = x + 1;
```

这里的 `x` 使用点找到可写的整数绑定，右侧字面量得到整数类型。加法根据两个孩子得到自己的 `i32` 结果，但整个加法并未因此成为可赋值的位置。每层表达式需要按自身规则产生结论，不能直接复制一个孩子的全部属性。

位置性质称为 `place`，表示表达式能够定位到存储位置。[place 与借用](/posts/13.1)会进一步区分可定位与可写。眼下它说明：仅保存类型仍不够，后续操作还要知道当前表达式可以怎样使用。

检查结论可以先返回父表达式，再按 `NodeID` 留在表中。隐式解引用、借用等调整也随相关节点保存，多步调整保留发生顺序。离开局部块会退出名字表，却无需删除这些已经确认的结论。

## 类型与常量记录

类型写法也有自己的节点。**类型解析表把类型节点的 `NodeID` 对应到已经确定的语义类型。** 常量结果则按常量声明保存，使用它时还能找到声明类型。

```rust
const N: usize = 3;
fn main() {
    let a: [i32; N] = [0; N];
}
```

`N` 的声明记录说明它是谁以及声明类型为 `usize`，常量记录保存值 3。`a` 的类型节点解析成 `[i32; 3]`；初值节点另有自己的表达式类型。类型相同需要比较解析后的元素、长度或具体声明，单看节点编号无法作出判断。

几类记录由不同问题产生，又通过节点和声明编号相连。打印成 `[i32; 3]` 方便阅读，后续仍可以直接取得元素类型与长度。错误另外保存，即使某些记录已经存在，也需要查看整份程序是否通过检查。
