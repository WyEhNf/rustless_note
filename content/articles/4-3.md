## 函数的层次结构

前面分别讨论了几种节点，现在把它们放回函数。可以从声明上的类型开始，再进入函数体，看看两条线在哪里相遇。

```rust
struct Row { data: [i32; 3] }
const N: usize = 3;
fn first(row: &Row) -> i32 { row.data[0] }
```

`Row` 声明连接字段 `data`，字段继续连接数组类型；`N` 连接声明类型与初值；`first` 连接参数 `row`、结果 `i32` 和函数体。参数上的引用继续指向 `Row`。数组长度和常量初值都包含编译期内容，后面还要解析名字并求值。若声明附带生命周期参数或使用处附带类型实参，这些信息也要放回所属位置。这样看每种构造动作，都能知道它在整棵树中负责哪一段。

进入块以后，按语句顺序继续读。遇到初值、条件或尾部结果时，再沿相应的表达式往下走。

```rust
fn f(x: i32) -> i32 {
    let a = [x, x + 1];
    if x > 0 { a[1] } else { a[0] }
}
```

`let` 的初值进入数组，数组第二个元素继续进入加法。尾表达式进入 `if`，条件进入比较，两条分支分别进入下标。其中名字和整数是基本节点；数组、加法、比较、`if` 与下标负责连接更深的内容。每次构造还需要保留位置，方便后面指出具体错误。按这个路线阅读，构造动作就能与程序片段一一对应，无须先背下一长串函数名。
