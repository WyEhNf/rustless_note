## 函数的检查上下文

函数签名给出的类型，在进入函数体时变成具体检查依据。参数需要按名字可查，尾表达式需要满足返回要求，内层块与循环又会逐渐增加新的局部信息。

签名已经确定参数类型，进入函数时再把参数名、类型、可变性和声明编号连起来。这样函数体中的名字使用就能找到相应参数。每个函数有自己的局部环境，退出一个函数以后，后一个函数不能继续使用它的参数或循环记录。

```rust
fn inc(mut x: i32) -> i32 {
    x += 1;
    x
}
```

`x` 在参数层登记成可变的 `i32` 绑定，函数体的块再增加一层作用域。检查赋值时能找到 `x`，并确认它可写。最后的 `x` 作为尾表达式，提供签名要求的 `i32`。若去掉参数上的 `mut`，读取 `x` 仍然可以，修改它则需要报告错误。

## 局部绑定的生效顺序

作用域说明当前位置可以使用哪些名字。查找从最近一层开始，退出内层块以后，后续使用又能看到原来的外层绑定。同名的新绑定叫遮蔽，或 `shadowing`。

```rust
let x = 1;
{
    let x = x + 1;
    let y = x;
}
let z = x;
```

内层 `let` 的初值先找到外层 `x`，得到旧值加一；初值检查完后，新 `x` 才在内层生效，所以 `y` 找到新绑定。离开块以后，`z` 重新找到外层 `x`。为保证这个顺序，`let` 要先检查右边，再登记左边的新名字。

当前 `let` 的类型也在这次检查中确定。后面的调用即使需要另一个整数类型，也不会自动回头改变已经得到的绑定类型。因此局部绑定除了确定名字的生效范围，也确定这一次声明已经得到的类型。

## 方法与循环

方法中的 `self` 是接收者绑定。可以把 `&self` 理解成名字为 `self`、类型为 `&Owner` 的参数，其中 `Owner` 是方法所属的结构体。大写 `Self` 则根据这个所属关系解释类型或关联路径。一个用于找到具体值，一个用于说明所属类型。

循环还需要单独维护当前所在的循环层次。`break` 和 `continue` 根据它寻找目标，`break` 携带的值也要放进对应循环的结果记录。表达式递归负责回到父表达式，作用域负责名字可见性，循环记录负责跳转，这三类关系要分别维护。

## 函数返回要求

函数的尾表达式接收返回类型要求；`return` 则根据当前函数要求检查携带值，然后直接离开函数。`return` 自身具有 `Never` 类型，说明当前表达式不会正常继续，但它带出的值仍然要符合签名。

**作用域决定名字指向谁，上下文决定当前位置允许做什么。**

同一个块里的名字使用、跳转和尾值虽然相邻，却会读取不同的信息。把当前函数、局部名字与循环分别维护，嵌套再深也能找到各自对应的要求。
