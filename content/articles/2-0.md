## 根节点与顶层声明

上一章已经说明源码怎样变成树。这一章把视角放到整份程序上：根节点包含什么，各类声明怎样连接自己的内容，进入函数以后又怎样继续向下。

AST 的根叫 `Crate`，可以理解成这一份程序的总入口。它按源码顺序保存顶层声明，每条这样的声明称为 `Item`。当前主要讨论结构体、常量、函数、`impl` 和 `use` 五类。它们承担的事情不同，所以内部保存的内容也不同。

```rust
struct Point { x: i32 }
const STEP: i32 = 1;
impl Point {
    fn read(&self) -> i32 { self.x }
}
fn main() {
    let p = Point { x: STEP };
    let n = p.read();
}
```

根下依次是 `Point`、`STEP`、`impl` 和 `main`。`let p` 与 `let n` 则放在 `main` 的函数体里。这样，读取顶层声明时可以先知道有哪些类型和函数，真正检查执行内容时再进入函数体。

## 声明的组成

`Point` 需要保存字段 `x`，以及它声明的 `i32` 类型。`STEP` 除了名字和类型，还要保存初值 1。`impl` 需要知道目标类型是 `Point`，才能说明 `read` 归属于谁。这个所属关系也叫 `owner`，之后使用 `Point::read` 时会用到它。

函数把声明和执行内容接起来：参数与返回类型规定怎样调用，函数体说明里面做什么。`read` 的 `self` 是接收者，表示这次操作的那个 `Point`；`main` 没有显式结果类型，正常结束时得到 `Unit`，写作 `()`，表示没有额外数据。

`use` 还会写出导入关系。不过当前范围主要保留这种写法，通用模块导入还需要额外的名字查找规则。读 AST 时要记住这一点，不能仅凭树里出现 `use` 就推断导入已经可用。

## 主干与递归连接

可以把主要连接概括成：`Crate` 包含 `Item`，函数 `Item` 连接块，块按顺序包含语句，语句再连接初值等表达式。表达式里还能继续有表达式，例如调用的实参、加法的左右两边，或者分支里的块。

在上面的例子里，`main` 先连到函数体，第一条 `let` 的初值再连到结构体构造，构造中的字段 `x` 连到名字 `STEP`。第二条 `let` 则连到方法调用，调用又连到接收者 `p`。

**读一条连接时，要同时看孩子是什么，以及它在父节点里担当什么角色。**

字段值需要保留字段名，减法需要分清左右顺序，调用需要区分被调用者与实参。用列表还是单个连接保存孩子，取决于这些具体需要。

## 共同信息

各类节点可以共享编号、位置和类别。进一步读懂节点，还需要操作符、名字和孩子等内容。表达式统一称为 `Expr`，内部却可以是字面量、调用、加法或块，形式不同，读取方法也不同。

`Type` 表示源码中的类型写法，会出现在字段、参数、返回类型和局部标注等多处。因此四层主干只是帮助抓住整体，类型子树与表达式的递归还会穿过这些层次。本章把主干看清后，下一章继续单独展开 `Type` 和路径。
