## Expr：表达式的组合

**`Expr` 表示表达式，是能够参与求值、继续组成更大表达式的程序结构。**

理解它时，可以先从直接的值和名字开始，再看它们怎样组成数组、结构体或更大的计算。每加上一种形式，都要说明它包含哪些孩子。

```rust
let a = [1, 2, 3];
let b = [0; 3];
```

`a` 需要保留三个元素，并逐个检查类型。`b` 需要保留初值 0 和次数 3，后面再确认次数是合法的编译期常量。若次数写成 `N`，先保留对 `N` 的引用，求值留到语义分析。受限的常量表达式还可以包含负号或括号，例如 `-N`。树先记录“写了什么”，之后再决定“这个次数是否允许”“重复初值是否需要 `Copy`”。

分支和循环让这种组合更明显：**条件要先求值**，内部又各自带着块。

```rust
let x = if flag { 1 } else { 2 };
while x > 0 { work(); }
```

`if` 连接条件 `flag`、`then` 块和 `else` 块。`while` 连接比较表达式 `x > 0` 与循环体。比较表达式还连接 `x` 和 0。`else if` 可以直接把另一个 `if` 放在 `else` 的位置。`loop` 则只需要循环体，没有显式条件。这样从表达式进入块，再由块进入表达式，就形成了笔记中反复出现的递归嵌套。

一元运算保存一个操作数，二元运算和赋值保存两个，转换则还需要保存目标类型。转换同样能一层套一层。每一层都保留之后，最终结果才会由最外面的转换决定。

```rust
let x: i32 = -1;
let y = x as u32 as usize;
```

先读取 `x`，再转换成 `u32`，最后把这个转换结果继续转换成 `usize`。结构可以从外向内读成“转 `usize`，里面是转 `u32`，里面是 `x`”。只留下最后一个目标类型，会抹掉中间步骤；只留下第一个目标类型，又无法表示最终结果。负号同样包住一个表达式。表达式树通过层层包裹，保留每次操作及其先后依赖。

### 后缀与表达式嵌套

而调用、字段和下标可以连续写在一个表达式后面。读到新的后缀时，就把前面得到的整体继续包进去。

```rust
make()[i].get()
```

先调用 `make`，得到一个值；再用 `i` 访问其中的元素；最后把这个元素作为接收者调用 `get`。`.x` 只有字段名，表示字段访问；`.get()` 带括号，表示方法调用。普通 `f(x)` 则保存被调用者 `f` 与实参 `x`。这里“后缀”说的是操作写在已有表达式后面。逆波兰记法 `a b +` 讨论的是另一种表达式记法，不能仅凭同一个词把二者混在一起。

有些表达式还会改变执行位置。跳转时需要留下目标判断所需的信息，以及可能携带的值。

```rust
loop {
    if ready { break 3; }
    continue;
}
return 4;
```

`break` 保存要带出的整数 3，`return` 保存要返回的整数 4。`continue` 没有额外携带值。这些写法出现在树里，不代表位置已经合法。后面需要知道当前是否处于循环、当前函数要求什么返回类型。`break;` 和 `return;` 没有显式值，检查时按 `Unit` 处理。循环结果和函数结果分别由各自的规则确定。

## 优先级与顺序

同一串词可以有不同的分组方式。优先级决定不同运算怎样分组，**结合方向**决定同级运算怎样分组。它们确定先把哪一部分组成子树，AST 再用父子关系把这个结果留下来。

```rust
10 - 3 - 2
10 - (3 - 2)
1 + 2 * 3
```

第一行按左结合组织成 `(10 - 3) - 2`，结果是 5。第二行由括号改成右侧先算，结果是 9。第三行的乘法优先级更高，因此加法右侧是一整棵乘法子树。顺序收集同级操作时，可以把此前结果继续放到新节点左侧。递归处理子规则负责保留不同优先级，逐个包裹同级运算负责保留结合方向。

文法中也会有只负责分层、没有新增操作的规则。经过这些层时，实际的表达式可以继续向上传递。

```rust
(((x)))
a = b = c
```

第一行的三层括号没有增加计算；分组作用确定以后，可以直接留下 `x`。第二行具有真实的赋值操作。若文法按右侧递归组织，就会得到 `a = (b = c)`，内部赋值需要保留。不过赋值表达式得到 `Unit`。如果 `a`、`b`、`c` 都是整数，外层会试图把 `Unit` 赋给 `a`，语义检查仍然会拒绝。能建出树与能通过类型检查要分步理解。

去掉空包装以后，孩子原来的顺序和角色仍然需要保留。尤其是减法、赋值与调用，交换位置就可能改变含义。

```rust
a - b
values[i]
while flag { work(); }
f(x, y)
```

减法先保存左边 `a`，再保存右边 `b`；下标先保存容器 `values`，再保存索引 `i`；`while` 先保存条件，再保存循环体。调用先找到 `f`，再读取 `x` 和 `y` 两个实参。方法调用则先保存接收者，再保存显式实参。块还需要语句列表，结构体构造需要带字段名的初值列表。不能假定所有内容都塞进一种不分角色的孩子数组。
