## 两遍检查的完整例子

前面的规则可以放回同一份小程序里。读这个例子时，先抓住常量、结构体和两个函数之间的关系，再往 `main` 的每条表达式里走。

```rust
const N: usize = 2;
#[derive(Copy, Clone, PartialEq, Eq)]
struct Point { x: i32 }
impl Point {
    fn read(&self) -> i32 { self.x }
    fn bump(&mut self, d: i32) { self.x += d; }
}
fn inc(x: i32) -> i32 { x + 1 }
fn main() {
    let mut p = Point { x: 1 };
    let values: [i32; N] = [p.read(); N];
    p.bump(values[0]);
    let x = p.read();
    let x = inc(x);
    let answer: i32 = loop {
        if x > 0 { break x; }
        break 0;
    };
    printlnInt(answer);
}
```

`N` 决定数组长度。`p` 从 `x`=1 开始，`read` 提供数组初值，`bump` 用数组元素修改 `p`。随后第二个 `x` 通过 `inc` 使用并遮蔽旧 `x`，`loop` 再选择带出哪个整数。

这里给出的是供分析的源程序，不包含编译器自身代码。接下来分开看树、第一阶段、第二阶段和几个具体结论。按这些操作的通常含义，可以推演 `answer` 为 3；这是手工推演，未在这里作为运行测试结果。

要在 AST 中找到这些操作，可以先截取 `main` 里的两条语句。它们分别展示了调用中的下标，以及 `let` 初值中的调用。

```rust
p.bump(values[0]);
let x = inc(x);
```

`main` 的第一段片段是方法调用，接收者为 `p`，显式实参是下标表达式；下标里面还有 `values` 和整数 0。第二段是局部绑定，初值是一处调用。调用目标位置保存 `inc` 的名字，实参保存旧 `x` 的使用。整份例子根下依次是常量 `N`、结构体 `Point`、`impl` `Point`，以及 `inc`、`main` 两个函数。`main` 的块再按顺序保存各条语句。

树的主干清楚以后，第一遍按这些声明准备类型与签名。下面几行摘出了后面反复会用到的要求。

```rust
const N: usize = 2;
#[derive(Copy, Clone, PartialEq, Eq)]
struct Point { x: i32 }
impl Point {
    fn read(&self) -> i32 { self.x }
    fn bump(&mut self, d: i32) { self.x += d; }
}
```

`N` 的类型是 `usize`，值为 2。`Point` 的字段 `x` 是 `i32`，对象大小可以有限确定，字段也支持所请求的四种能力，显式依赖齐全。`read` 需要共享接收者并返回 `i32`；`bump` 需要可变接收者、一个 `i32` 参数，返回 `Unit`。再确认 `inc` 的输入输出均为 `i32`，以及 `main` 无参数且返回 `Unit`，就为逐个函数体检查准备好了要求。

这些要求准备好后，第二遍进入 `main`。这里先沿着几条相接的语句，观察类型要求和局部绑定如何变化。

```rust
let mut p = Point { x: 1 };
let values: [i32; N] = [p.read(); N];
p.bump(values[0]);
let x = p.read();
let x = inc(x);
```

`p` 可写。`read` 自动共享借用接收者，结果 `i32` 可按 `Copy` 重复 `N`=2 次。下标 0 按 `usize` 检查，取出的 `i32` 满足 `bump` 参数，`p` 也满足可变接收者要求。**第二次 `let` `x` 先检查** `inc(x)`，其中仍找到旧 `x`，之后才让新绑定生效。

完整例子里的 `loop` 接收 `i32` 标注，两个 `break` 都提供 `i32`；`printlnInt` 接收这个整数并返回 `Unit`，使 `main` 正常结束。

最后回到几个具体表达式，比较它们留下的结果。这样就能把“检查通过”进一步展开为每个节点已经确定了哪些信息。

```rust
p.read();
values[0];
inc(x);
loop { break x; }
```

`p` 的名字使用记录局部声明及可写性；`read` 调用记录 `Point::read`、`i32` 结果和共享借用；下标记录元素 `i32`、位置性质，以及索引的 `usize` 类型。`inc` 调用关联 `inc` 声明并得到 `i32`。`break` 自身为 `Never`，却把 `x` 的 `i32` 类型记入循环结果，`loop` 最终可以得到 `i32`。

这些例子把声明身份、类型、权限和调整分别放回各自节点，后面就能直接使用已经确认的关系。
