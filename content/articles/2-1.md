## Crate：整份程序

AST 最上面的根叫 **`Crate`**。它按顺序容纳顶层声明，每个这样的声明称为一个 **`Item`**。先把这一层看清楚，再进入函数体，结构就比较容易跟上。

```rust
struct Point { x: i32 }
const N: usize = 3;
fn main() { let p = Point { x: 1 }; }
```

这份程序在顶层有结构体、常量和函数三个声明，按源码顺序排在根下。`let p` 写在 `main` 的大括号里，属于函数体中的语句。沿着 `main` 找到块，再从块找到这个绑定。这样分层后，查看顶层声明不必把函数体中的每条语句混进来。需要检查函数执行内容时，再往函数体里走。

例子里的 `i32` 是 32 位有符号整数；`usize` 是随目标大小确定的无符号整数，这里按 32 位目标讨论。字段 `x` 属于 `Point`，常量 `N` 的值在编译期确定。

## Item：声明单元

在当前讨论的范围里，`Item` 主要有五类。下面把其中四类放到一起，看看每一类需要说明什么。

```rust
struct Point { x: i32 }
const LIMIT: i32 = 10;
fn zero() -> i32 { 0 }
impl Point { fn get(&self) -> i32 { self.x } }
```

`Point` 说明字段怎样组合；`LIMIT` 同时给出类型和初值；`zero` 给出参数、结果和函数体；`impl` `Point` 把 `get` 归到 `Point` 名下。第五类是 `use`，用来写导入关系，例如 `use a::b;`。这里先保留其写法，通用导入查找还需要额外支持。

声明还可能附带 `derive` 或生命周期参数。`derive` 请求按字段提供某种能力，能力名叫 `trait`；生命周期参数给引用有效期起名字。这些内容会在后面展开。

## 声明的内容

顶层声明并不只保存一个名字。结构体要说明字段，常量要说明类型和初值，`impl` 则要说明这一组成员属于哪个类型。

```rust
struct Point { x: i32 }
const LIMIT: i32 = 10;
impl Point {
    const ZERO: i32 = 0;
    fn get(&self) -> i32 { self.x }
}
```

字段 `x` 连接 `i32`，说明这个位置放整数。`LIMIT` 还连接初值 10，因为声明类型与实际初值都要检查。`impl` 的目标是 `Point`，里面的 `ZERO` 和 `get` 都归属 `Point`。这个**所属类型**也叫 `owner`，后面可以按 `Point::ZERO` 和 `Point::get` 查找。

只记下成员名 `get` 还不够；另一个结构体也可能有 `get`。保留所属类型，才能把这两者分开。

函数也有声明上的要求，不过它还要连接实际执行的内容。参数和返回类型把这两部分联系起来。

```rust
fn add(mut x: i32, y: i32) -> i32 {
    x = x + y;
    x
}
```

`x` 和 `y` 都是 `i32` 参数，`mut` 表示 `x` 这个绑定可以重新赋值。最后的 `x` 没有分号，给函数体提供结果，符合声明中的 `i32`。若省略返回类型，例如 `fn f() {}`，正常结果是 `Unit`，写成 `()`，表示没有额外数据。

方法还带有接收者。`fn set(&mut self, value: i32)` 中，`self` 表示被操作的对象，`value` 是显式传入的参数。两者需要分别记录，检查调用时再放到一起。

还有一种声明需要单独留意：`use` 写下了希望怎样导入名字。要让这个名字真的可用，后续还得有相应的查找规则。

```rust
use a::b;
fn main() {
    b();
}
```

第一行说明希望通过 `b` 使用 `a` 中的声明。若只保留了这行文本，却还没有建立导入关系，第二行仍然无法凭空找到 `b`。当前讨论的语言范围只保存 `use` 的写法，没有通用模块导入。因而不能看到 AST 里有 `use`，就推断模块查找已经完整可用。完整语言还要找到模块 `a`、确认其中的 `b`、处理名字冲突，再让 `b` 在相应范围内可见。
